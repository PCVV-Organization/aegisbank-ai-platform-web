perf(service-requests): add bounded query cache

Reduce duplicate Core Banking reads while keeping customer-visible request data fresh. TanStack Query now retains a customer-scoped result for 15 seconds and garbage-collects it after five minutes; active queries revalidate on mount and reconnect. Successful mutations still invalidate and await a server refresh, while failed writes preserve the previous state.
